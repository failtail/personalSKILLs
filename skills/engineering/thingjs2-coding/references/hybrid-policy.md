# ThingJS 2.0 hybrid evidence policy

Use the smallest sufficient evidence source for the task:

1. the versioned Contract and current project Overlay for machine decisions;
2. approved Context7 official libraries when retrieval is active;
3. official ThingJS API, documentation, and example pages as fallback;
4. local engineer corpus only for project practice, Recipes, and Incidents.

Context7 results require exact public owner/member, signature, original official
URL, and ThingJS 2.0 scope checks. A partial, unavailable, polluted, wrong-owner,
private-page, or source-less result remains an Incident. Internal sources stay in
the user-level workspace and never enter this public Skill. Runtime Surface proves
existence only; behavior is promoted through separate tests. A controlled
target-version mismatch blocks, while an unversioned latest official change creates
`stale_review`. Neither outcome rewrites the underlying official evidence.
